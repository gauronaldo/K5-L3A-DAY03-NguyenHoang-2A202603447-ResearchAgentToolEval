🔎 Research Agent

Agent nghiên cứu tin AI/tech: tìm tin theo chủ đề hoặc theo tài khoản, đọc URL, tra Wikipedia / Hacker News / GitHub / arXiv / policy nội bộ, trích dẫn nguồn có phân tier, và chỉ gửi Telegram sau khi bạn xác nhận. Thiếu thông tin thì hỏi lại, không đoán.

  3. Cộng đồng Hacker News đang bàn gì về Claude?
  4. Retrieval-augmented generation là gì? Tra Wikipedia
  5. Repo GitHub nhiều sao nhất về AI agent framework?

  7. Đăng bản tin này lên Telegram (→ agent xin xác nhận yes/no)

Guardrails

  • Không đoán handle / URL → clarify
  • Không gửi khi chưa xác nhận; confirmed="false" dạng chuỗi cũng bị chặn
  • Toán / code / chit-chat → từ chối, không gọi tool
